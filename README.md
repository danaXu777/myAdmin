# myApp - 登录注册系统

## 技术栈
- 前端：Vue3 + Vite + Element Plus + Pinia + Vue Router
- 后端：Node + Express + SQLite + JWT + bcrypt

## 目录结构
- client/  前端工程
- server/  后端工程
- docs/    文档

## 本地启动

### 后端
cd server
npm install
npm run dev

### 前端
cd client
npm install
npm run dev

## 访问
- 前端：http://localhost:5173
- 后端：http://localhost:3000
