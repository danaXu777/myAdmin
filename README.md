# myAdmin

一个基于 Vue3 + Node 的企业后台管理系统模板。

## 技术栈

**前端**
- Vue3 + Vite
- Element Plus
- Vue Router 4
- Pinia
- Axios
- ECharts

**后端**
- Node + Express
- SQLite（开发）/ PostgreSQL（部署）
- JWT 认证
- bcrypt 密码加密

## 本地启动

### 后端

cd server
npm install
npm run dev

访问 http://localhost:3000

### 前端

cd client
npm install
npm run dev

访问 http://localhost:5173
